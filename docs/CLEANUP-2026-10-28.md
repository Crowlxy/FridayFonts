# 2026-10-28 の整理：削除したものと理由

古い版・試作のスクリプトと記録が混ざり、どれが今のビルドに要るのか分からなくなっていたため、使っておらず、現行のドキュメントからも参照されないものを削除しました。**削除はGitの履歴に残っています。整理の直前のコミットは `b64f582` で、そこから取り出せます**（`git show b64f582:<パス>`、またはフォルダごと `git checkout b64f582 -- <パス>`）。

## 判断の基準

次のすべてに当てはまるものを削除しました。

1. 現行のビルド（Mono 5.x：`scripts/mono50/`、Sans 3.x：`scripts/sans30/`）と検査（`scripts/qa/`）から、import・呼び出し・パスのどれでも参照されていない。
2. README・`docs/BUILDING.md`・`docs/FONT-TOOLS.md` が「いま使う」ものとして案内していない。
3. 出力（配布済みのZIPと記録）はすでに公開済みか、公開しないと決めた版のものである。

Mono 5.0以降・Sans 3.0以降は、配布済みのZIP（Mono 4.93、Sans 2.5・3.002）を入力にするため、それより前の工程を再実行する必要がありません。

- `GdiAudit.cs` を `scripts/mono50/windows/` に移し、`gdi_all_glyphs.ps1` の参照を直した（Windows GDI検査が使う）。
